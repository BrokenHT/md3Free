构建环境
Flutter 3.47.5 / Dart 3.13.4
Android：JDK 22、Android SDK 36、Build Tools 36、NDK 28.2.13676358。
Windows：Visual Studio C++ 桌面工具链与 Windows SDK 10.0.26100 或更新版本。

Android arm64 标准功能版
1. flutter pub get
2. python -m pip install PyYAML
3. python scripts/prepare_android_release.py
4. 配置自己的 android/keystore.properties；签名文件不随源码分发。
5. flutter build apk --release --flavor lite --target-platform android-arm64 --no-pub
输出：build/app/outputs/flutter-apk/app-lite-release.apk
lite 是本项目的标准功能 flavor，不包含完整包额外的本地 AI 模型。
生产注册脚本用于排除 integration_test 等开发插件；运行测试前可再次 flutter pub get。

Windows
flutter pub get
flutter build windows --release
发布整个 Release 目录，不能仅分发 exe。

静态唱片素材
assets/images/record_sleeve_dark.png 与 record_sleeve_light.png 是程序生成的共享透明纹理。
生成源码：test/tooling/export_record_sleeve_test.dart。
需要重做材质时设置 MD3FREE_EXPORT_RECORD_TEXTURES=1，再运行该测试。
翻阅过程中仅进行图片变换，不逐帧绘制唱片纹路和玻璃材质。

性能取样
lib/core/services/frame_timing_probe.dart 仅在显式传入 MD3FREE_FRAME_LOG 时启用。
正式构建不传入该参数。F11/F12 的取样控制不会出现在正式版中。
